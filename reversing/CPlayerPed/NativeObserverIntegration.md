# Detached native observer API

No hook or VEH is installed by these artifacts. ReIV.cpp, existing probes and reconstructed caller headers were not modified. Native game validation remains pending.

Include `native-clone/native-validation.h`, `native-clone/templates.h` and `NativeObserverBridge.h`. Keep a `reiv::player_native::ValidatedResolver` and `reiv::player_clone::CoffClone` alive for the entire observer lifetime. Run `ValidateCurrentGame(resolver,error)` before creating the clone. A context-free callback adapter forwards `(Kind,VA)` to `resolver.Resolve`. Create the Update clone with `UpdateBody`; `Entry()` is exposed only after successful patching and RX/RO publication.

The resolver validates the current main executable SHA256, PE32 format, all three complete original caller bodies with PE relocation operands adjusted for ASLR, 42 external callee entry signatures and the player vtable slot29. Original validation bytes are never executed or represented as reconstructed source. Calls resolve only to the verified callee allowlist. Global/opaque-object references resolve only to recognized compiled-source operands, with observed operand widths. Opaque-object pointer mapping establishes identity/accessibility, not the dependent object's full layout. New binding creation must be serialized; source fixture snapshots are never copied to game memory.

Configure `reiv::player_observer` before publishing the vtable thunk: `originalEntry`, `cloneEntry`, `cloneBegin`, `cloneEnd`, `targetPlayer` and zeroed counters. Start with `enabled=0`. Thunk preserves all general registers, EFLAGS and the original stack/ECX, selects using integer atomic counters, then tail-jumps to the complete original or clone. It adds no return address or FP operation. Non-target receivers always go to the original.

For an opt-in natural-call experiment, atomically replace the aligned DWORD at `loadedBase + 0x009819C4 + 29*4`, after verifying the current slot still equals the validated original Update address. Do not call complex methods artificially. Observe at least32 **target** original dispatches before switching `enabled=1`; require64 target clone dispatches with no recorded exceptions before ending the sample. `calls-selected` is the report's total `original_calls`; use `targetCalls-selected` for the32-call local-player gate so other receivers cannot satisfy it. `selected` counts clone dispatch attempts, not independently instrumented completion returns.

The optional `NotifyException` callback never swallows exceptions. It only attributes exceptions whose instruction address lies inside clone code, increments `exceptions`, disables future clone selections and returns `EXCEPTION_CONTINUE_SEARCH`. Exceptions in external callees remain unattributed. Never invoke the original as recovery after a failing clone call: partial writes could make that a second update. No in-game equivalence comparison is available during natural-call replacement.

To end the sample, disable future selections, restore the slot atomically only if it still points to this thunk, then verify restoration before reporting `restored=true`. Do not overwrite another mod's changed slot. Keep clone code, callback cells, tables and bridge alive while any thread could still be using the old slot/thunk; simply disabling does not establish quiescence. Removing the VEH registration also requires normal lifecycle coordination. The experiment must remain explicitly opt-in.

Current detached tests: 16384 bridge cases preserve general registers/flags/stack and complete FXSAVE state, target filtering and counters; synthetic exception notifications continue search and disable only recognized code addresses. Resolver tests verify the canonical file hash, reject a non-game process and missing files, and return no callable addresses before validation. Accepted native game mappings and vtable publication have not yet been exercised.
