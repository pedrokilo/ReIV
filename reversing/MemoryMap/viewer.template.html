Cómo leer el mapa
Una clase no tiene una única dirección. La ficha puede señalar su descriptor RTTI, una o varias vtables y las funciones de sus slots. Las instancias se crean en runtime y no tienen una dirección fija en este inventario.
VA estática = base preferida + RVA. La columna calculada usa la base que escribas arriba, no una base observada del proceso. Los offsets de miembros de una clase son otra cosa.
RTTI se obtiene del EXE y las vtables se enlazan mediante estructuras comprobadas. Las funciones de Ghidra son entradas detectadas: pueden incluir librerías, thunks y candidatos mal delimitados. El análisis global es parcial. Las direcciones del SDK y el documento conservan su procedencia, pero su semántica no se valida por aparecer dentro de una sección.
No existe todavía un total demostrado de clases o funciones del juego. Los tipos incluyen plantillas y componentes externos; una base RTTI puede ser transitiva. Los límites de vtables se estiman leyendo punteros consecutivos a código.
